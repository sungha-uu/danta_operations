완전 자동 로테이션

보유 한도 3종목이 찬 상태에서도 모든 보유종목과 최종 후보를 비교합니다.

  1. 후보 점수가 보유종목보다 12점 이상 높고 같은 교체쌍이 3회 연속 관측되면 로테이션을 확정합니다.
  2. 하루 최대 3회, 한 번에 한 교체쌍만 처리합니다.
  3. 기존 종목 전량 매도를 정상 주문 경로에 넣습니다.
  4. KIS 체결과 잔고에서 기존 종목이 실제로 사라졌는지 대조합니다.
  5. 신규 후보의 최신 점수·가격·데이터 안전성을 다시 확인한 뒤 새 진입 명령을 만듭니다.
  6. 최대 매수가 이하에서 하락 안정·매수세 회복이 확인될 때 신규 후보를 매수합니다.

매도 미체결·부분체결, 잔고 불일치, 후보 우위 소멸, 데이터 노후화가 있으면 신규 매수로 넘어가지 않습니다. 손절·익절 주문은 로테이션보다 우선합니다.

보유종목 실시간 모니터링

  • 보유종목은 후보 10분 배치와 별개로 실시간 체결·호가·가격을 감시합니다.
  • WebSocket 누락은 REST 감시가 보완하며, KRX와 NXT 세션을 하나의 포지션 상태로 이어갑니다.
  • PC 재시작 시 KIS 주문·체결·잔고를 먼저 대조한 뒤 기존 보호 감시를 복구합니다.
  • 외부 AI 응답이나 GitHub Pages가 끊겨도 로컬 손절·익절 경로는 계속 동작합니다.
